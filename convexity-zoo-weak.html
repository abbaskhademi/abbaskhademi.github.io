Definitions & main properties

Each numbered entry is based on the matching statement in the paper. Notes summarize the definition or the role of the result; see the original paper for all hypotheses and proofs.

Definition

4.1 · Weakly Convex Function

Weak convexity allows controlled quadratic deviation below the convex chord.

f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y) + (ρ/2)λ(1−λ)‖x−y‖².

Source: Khademi (2026), Definition 4.1, p. 4228 ↗

Property

4.2 · Quadratic Convexification

f is ρ-weakly convex exactly when f+(ρ/2)‖·‖² is convex.

Source: Khademi (2026), Property 4.2, p. 4228 ↗

Property

4.3 · First-Order Characterization

A quadratic-corrected supporting gradient inequality characterizes smooth weak convexity.

Source: Khademi (2026), Property 4.3, p. 4228 ↗

Property

4.4 · Second-Order Characterization

Twice differentiable weak convexity is equivalent to ∇²f ⪰ −ρI.

Source: Khademi (2026), Property 4.4, p. 4228 ↗

Property

4.5 · Smoothness Implies Weak Convexity

An L-Lipschitz gradient makes both f and −f L-weakly convex.

Source: Khademi (2026), Property 4.5, p. 4228 ↗

Property

4.7 · Hessian-Based Weak Convexity

A uniform Hessian lower bound provides a weak convexity parameter on compact convex sets.

Source: Khademi (2026), Property 4.7, p. 4229 ↗

Definition

4.8 · Para-Convex Function

Generalized para-convexity replaces the quadratic error with a power 1+ν, ν∈(0,1].

f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y) + (ρ/2)λ(1−λ)‖x−y‖^(1+ν).

Source: Khademi (2026), Definition 4.8, p. 4229 ↗

Property

4.9 · Recovery of Weak Convexity

The para-convex definition with exponent ν=1 recovers weak convexity.

Source: Khademi (2026), Property 4.9, p. 4229 ↗
