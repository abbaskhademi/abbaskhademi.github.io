Definitions & main properties

Each numbered entry is based on the matching statement in the paper. Notes summarize the definition or the role of the result; see the original paper for all hypotheses and proofs.

Definition

3.1 · Quasi-Convex Function

Quasi-convexity controls a point on a segment by the larger endpoint value, equivalently requiring convex sublevel sets.

f(λx+(1−λ)y) ≤ max{f(x),f(y)}.

Source: Khademi (2026), Definition 3.1, p. 4221 ↗

Property

3.2 · Sublevel Set Characterization

Quasi-convexity is equivalent to convexity of every sublevel set.

Source: Khademi (2026), Property 3.2, p. 4222 ↗

Definition

3.3 · Strictly Quasi-Convex Function

Strict quasi-convexity requires a strict upper bound on the interior of each nontrivial segment.

f(λx+(1−λ)y) < max{f(x),f(y)} for x≠y, 0<λ<1.

Source: Khademi (2026), Definition 3.3, p. 4222 ↗

Definition

3.4 · Semistrictly Quasi-Convex Function

Semistrict quasi-convexity imposes strict segment decrease whenever the endpoint function values differ.

f(x)<f(y) ⇒ f(λx+(1−λ)y)<f(y), 0<λ<1.

Source: Khademi (2026), Definition 3.4, p. 4222 ↗

Property

3.5 · Lower Semicontinuity and Quasi-Convexity

Discusses how lower semicontinuity interacts with semistrict quasi-convexity.

Source: Khademi (2026), Property 3.5, p. 4222 ↗

Property

3.6 · First-Order Characterization of Quasi-Convexity

Differentiable quasi-convexity admits a directional gradient implication for ordered function values.

Source: Khademi (2026), Property 3.6, p. 4222 ↗

Definition

3.7 · Strongly Quasi-Convex Function

Strong quasi-convexity combines the maximum-of-endpoints bound with a quadratic reduction.

f(λx+(1−λ)y) ≤ max{f(x),f(y)} − (μ/2)λ(1−λ)‖x−y‖².

Source: Khademi (2026), Definition 3.7, p. 4222 ↗

Property

3.8 · Characterization of Strong Quasi-Convexity

Gives a comparison inequality and a converse (under continuity) for strong quasi-convexity.

Source: Khademi (2026), Property 3.8, p. 4223 ↗

Definition

3.9 · Uniformly Quasi-Convex Function

Uniform quasi-convexity uses a general positive modulus in the quasi-convex inequality.

f(λx+(1−λ)y) ≤ max{f(x),f(y)} − λ(1−λ)φ(‖x−y‖).

Source: Khademi (2026), Definition 3.9, p. 4223 ↗

Definition

3.10 · Pseudo-Convex Function

For differentiable functions, a strictly improving point must lie in a strictly descending first-order direction.

f(x)<f(y) ⇒ ⟨∇f(y),x−y⟩<0.

Source: Khademi (2026), Definition 3.10, p. 4223 ↗

Definition

3.11 · Strictly Pseudo-Convex Function

Strict pseudo-convexity strengthens the preceding implication when x≠y, even for equal endpoint values.

x≠y and f(x)≤f(y) ⇒ ⟨∇f(y),x−y⟩<0.

Source: Khademi (2026), Definition 3.11, p. 4224 ↗

Property

3.12 · Critical Point Characterization of Pseudo-Convexity

For a differentiable quasi-convex objective on an open convex domain, pseudo-convexity is characterized by critical-point global optimality.

Source: Khademi (2026), Property 3.12, p. 4224 ↗

Definition

3.13 · Invex Function

Invexity replaces ordinary displacement by a possibly nonlinear vector kernel η.

f(x)−f(y) ≥ ⟨η(x,y),∇f(y)⟩.

Source: Khademi (2026), Definition 3.13, p. 4224 ↗

Property

3.14 · Critical Point Characterization of Invexity

Invexity with some kernel is equivalent to every critical point being globally optimal.

Source: Khademi (2026), Property 3.14, p. 4224 ↗

Property

3.15 · Convexity Implies Pseudo-Convexity

Differentiable convex functions are pseudo-convex; the converse need not hold.

Source: Khademi (2026), Property 3.15, p. 4224 ↗

Property

3.16 · Pseudo-Convexity Implies Quasi-convexity

Pseudo-convexity implies quasi-convexity; not conversely.

Source: Khademi (2026), Property 3.16, p. 4225 ↗

Property

3.17 · Convexity Implies Invexity

Differentiable convexity supplies an invex kernel from standard displacement.

Source: Khademi (2026), Property 3.17, p. 4225 ↗

Definition

3.18 · Quasi-Invex Function

Quasi-invexity requires directions that have positive kernel-gradient pairing to produce strictly larger function values.

⟨η(x,y),∇f(y)⟩>0 ⇒ f(x)>f(y).

Source: Khademi (2026), Definition 3.18, p. 4225 ↗

Property

3.19 · Quasi-Convexity Implies Quasi-Invexity

Differentiable quasi-convex functions meet a quasi-invex condition.

Source: Khademi (2026), Property 3.19, p. 4225 ↗

Property

3.20 · Invex Implies Quasi-Invex

Invexity entails quasi-invexity for the same kernel.

Source: Khademi (2026), Property 3.20, p. 4225 ↗

Property

3.21 · Fractional Invexity

Provides an explicit invex kernel for a convex numerator divided by a positive concave denominator.

Source: Khademi (2026), Property 3.21, p. 4225 ↗

3.22 · Characterization of Pseudo-Convexity via Kernel Structure

Characterizes a pseudo-convex subclass of invex functions by the structure of its kernel.

3.23 · Invexity under Scalar Transformation

3.25 · Closure under Nonnegative Linear Combinations

Definition

3.27 · Generalized rth Mean

The generalized power mean interpolates between ordinary, geometric, maximum, and minimum means as its parameter varies.

Mᵣ(a,b;λ) = [λaʳ+(1−λ)bʳ]^(1/r), r≠0; M₀=a^λb^(1−λ).

Source: Khademi (2026), Definition 3.27, p. 4226 ↗

Definition

3.28 · r-Convex Function

r-convexity bounds f along a segment by the logarithm of a power mean of its exponentiated endpoint values.

f(λx+(1−λ)y) ≤ log Mᵣ(eᶠ⁽ˣ⁾,eᶠ⁽ʸ⁾;λ).

Source: Khademi (2026), Definition 3.28, p. 4227 ↗

Property

3.29 · Interpretation of Limiting Cases

The r-mean family connects classical convexity and limiting quasi-convex/quasi-concave conditions.

Source: Khademi (2026), Property 3.29, p. 4227 ↗

Property

3.30 · Exponential Transformation Characterization

r-convexity can be tested by convexity/concavity of a suitable exponential transform.

Source: Khademi (2026), Property 3.30, p. 4227 ↗

Property

3.31 · Second-Order Characterization of r-Convexity

A modified Hessian, ∇²f+r∇f∇fᵀ, tests smooth r-convexity.

Source: Khademi (2026), Property 3.31, p. 4227 ↗

3.32 · Optimal r-Convexity Parameter for Quasi-Convex Functions

Source: Khademi (2026), Property 3.32, p. 4227 ↗
