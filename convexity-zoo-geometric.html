Definitions & main properties

Each numbered entry is based on the matching statement in the paper. Notes summarize the definition or the role of the result; see the original paper for all hypotheses and proofs.

Definition

5.1 · Star-Shaped Set

A star-shaped set contains the entire segment from a chosen star center to each point in the set.

λx*+(1−λ)x ∈ S for every x∈S and 0≤λ≤1.

Source: Khademi (2026), Definition 5.1, p. 4230 ↗

Definition

5.2 · Star-Convex Function

Star-convexity imposes the convex chord inequality only on segments pointing toward global minimizers.

f(λx*+(1−λ)x) ≤ λf(x*)+(1−λ)f(x).

Source: Khademi (2026), Definition 5.2, p. 4230 ↗

Definition

5.3 · Star-Convex with Respect to a Point

Pointwise star-convexity imposes the same inequality with respect to one specified center x*.

f(λx*+(1−λ)x) ≤ λf(x*)+(1−λ)f(x).

Source: Khademi (2026), Definition 5.3, p. 4230 ↗

Property

5.4 · Convexity Implies Star-Convexity

Convexity implies star-convexity at every global minimizer.

Source: Khademi (2026), Property 5.4, p. 4231 ↗

Definition

5.5 · Strongly Star-Convex Function

Strong star-convexity adds a uniform quadratic margin along segments to a minimizer.

f(λx*+(1−λ)x) ≤ λf(x*)+(1−λ)f(x) − (μ/2)λ(1−λ)‖x−x*‖².

Source: Khademi (2026), Definition 5.5, p. 4231 ↗

Property

5.6 · Strong Convexity Implies Strong Star-Convexity

Strong convexity implies strong star-convexity.

Source: Khademi (2026), Property 5.6, p. 4231 ↗

Property

5.7 · Epigraph Characterization

Star-convexity at x* corresponds to star-shapedness of the epigraph at (x*,f(x*)).

Source: Khademi (2026), Property 5.7, p. 4231 ↗

Property

5.8 · Star-Shaped Sublevel Sets

Sublevel sets of star-convex functions are star-shaped around global minimizers.

Source: Khademi (2026), Property 5.8, p. 4232 ↗

Property

5.9 · First-Order Characterization of Star-Convexity

A first-order inequality toward any minimizer is necessary for differentiable star-convexity.

Source: Khademi (2026), Property 5.9, p. 4232 ↗

Property

5.10 · First-Order Characterization of Strong Star-Convexity

Strong star-convexity admits a first-order inequality with a quadratic margin.

Source: Khademi (2026), Property 5.10, p. 4232 ↗

Property

5.11 · Necessary Second-Order Condition for Star-Convexity

At a star center, a twice differentiable star-convex function has a positive-semidefinite Hessian.

Source: Khademi (2026), Property 5.11, p. 4232 ↗

Definition

5.12 · Quasar-Convexity

γ-quasar-convexity weakens the radial inequality toward a global minimizer; γ=1 recovers star-convexity.

f(λx*+(1−λ)x) ≤ γλ f(x*)+(1−γλ)f(x), γ∈(0,1].

Source: Khademi (2026), Definition 5.12, p. 4233 ↗

Property

5.13 · Star-Convexity as a Special Case

γ=1 quasar-convexity is the star-convex condition.

Source: Khademi (2026), Property 5.13, p. 4233 ↗

Property

5.14 · First-Order Characterization of Quasar-Convexity

Provides the directional first-order characterization f(x)−f* ≤ ⟨∇f(x),x−x*⟩/γ.

Source: Khademi (2026), Property 5.14, p. 4233 ↗

Property

5.16 · Quasar-Convexity Parameter Ordering

Quasar-convexity with parameter γ₁ also holds for every smaller positive γ₂.

Source: Khademi (2026), Property 5.16, p. 4234 ↗

Property

5.17 · Stationary Points Are Global Minimizers

Stationary points of differentiable quasar-convex functions are globally optimal.

Source: Khademi (2026), Property 5.17, p. 4234 ↗

Property

5.18 · Quasar-Convexity Implies Invexity

Under its stated hypotheses, quasar-convexity implies invexity.

Source: Khademi (2026), Property 5.18, p. 4234 ↗

Definition

5.19 · Strongly Quasar-Convex Function

Strong quasar-convexity adds a quadratic decrease to the quasar-convex segment inequality.

See Definition 5.19 for the exact γ-, μ-, and λ-dependent quadratic coefficient.

Source: Khademi (2026), Definition 5.19, p. 4234 ↗

Property

5.20 · First-Order Characterization of Strongly Quasar-Convex Function

Strong quasar-convexity yields a first-order gradient inequality with a quadratic term.

Source: Khademi (2026), Property 5.20, p. 4235 ↗

Property

5.21 · Uniqueness of the Minimizer

Strong quasar-convexity implies uniqueness of the global minimizer.

Source: Khademi (2026), Property 5.21, p. 4235 ↗

Definition

5.22 · Projected Quasar-Convex Function

Projected quasar-convexity replaces a fixed minimizer by the nearest point xπ in the global minimizer set.

f(x)−f* ≤ (1/γ)⟨∇f(x),x−xπ⟩.

Source: Khademi (2026), Definition 5.22, p. 4235 ↗

Property

5.24 · Projected Quasar-Convexity Implies Quasar-Convexity

With the stated minimizer-set hypothesis, projected quasar-convexity implies standard quasar-convexity.

Source: Khademi (2026), Property 5.24, p. 4235 ↗

Definition

5.25 · Projected Strongly Quasar-Convex Function

The projected strong variant adds a negative quadratic distance term to the projected quasar-convex inequality.

f(x)−f* ≤ (1/γ)⟨∇f(x),x−xπ⟩ − (μ/2)‖x−xπ‖².

Source: Khademi (2026), Definition 5.25, p. 4235 ↗

Definition

5.26 · Tilted Convex Function

Tilted convexity uses different first-order slopes for directions with nonpositive versus nonnegative gradient pairing.

f(y) ≥ f(x)+a⟨∇f(x),y−x⟩; a=1/γ in descent directions, a=γ′ in ascent directions.

Source: Khademi (2026), Definition 5.26, p. 4236 ↗

Property

5.27 · Tilted Convexity Implies Quasar-Convexity

Tilted convexity provides sufficient structure for quasar-convexity.

Source: Khademi (2026), Property 5.27, p. 4236 ↗

5.28 · Smoothness Lower Bound

5.30 · Nonnegative Weighted Sums Preserve Quasar-Convexity

Nonnegative weighted sums retain quasar-convexity when the relevant minimizer is shared.

Definition

5.35 · Star Quasi-Convex Function

Star quasi-convexity requires that moving toward a chosen minimizer cannot increase the objective.

f(λx*+(1−λ)x) ≤ f(x).

Source: Khademi (2026), Definition 5.35, p. 4238 ↗

Property

5.36 · Star-Shaped Sublevel Sets

Star quasi-convexity at x* is equivalent to sublevel sets being star-shaped at x*.

Source: Khademi (2026), Property 5.36, p. 4238 ↗

Definition

5.37 · Strong Star Quasi-Convex Function

Strong star quasi-convexity adds a quadratic decrease along paths to a minimizer.

f(λx*+(1−λ)x) ≤ f(x) − (μ/2)λ(1−λ)‖x−x*‖².

Source: Khademi (2026), Definition 5.37, p. 4238 ↗
