Partial and pointwise convexity

Biconvexity, multiconvexity, pointwise and midpoint definitions.

Definitions & main properties

Each numbered entry is based on the matching statement in the paper. Notes summarize the definition or the role of the result; see the original paper for all hypotheses and proofs.

Definition

7.1 · Biconvex Function

Biconvexity means convexity in each of two variable blocks when the other is fixed.

x↦f(x,y) is convex for each y; y↦f(x,y) is convex for each x.

Source: Khademi (2026), Definition 7.1, p. 4244 ↗

Property

7.2 · Summation Closure for Biconvex Functions

Nonnegative weighted sums of biconvex functions remain biconvex.

Source: Khademi (2026), Property 7.2, p. 4244 ↗

Definition

7.3 · Multiconvex Function

Multiconvexity extends separate convexity from two to any finite number of variable blocks.

For each block i, xᵢ↦f(x₁,…,xᵢ,…,xₙ) is convex with other blocks fixed.

Source: Khademi (2026), Definition 7.3, p. 4244 ↗

Definition

7.4 · Convexity at a Point

Convexity at a point tests the convex chord inequality only relative to a fixed point x₀.

f(λx₀+(1−λ)x) ≤ λf(x₀)+(1−λ)f(x).

Source: Khademi (2026), Definition 7.4, p. 4245 ↗

Definition

7.6 · Pseudo-Convexity at a Point

Pseudo-convexity at a point requires a nonnegative directional derivative from x₀ to imply no decrease in value.

⟨∇f(x₀),x−x₀⟩≥0 ⇒ f(x)≥f(x₀).

Source: Khademi (2026), Definition 7.6, p. 4245 ↗

Definition

7.7 · Quasi-Convexity at a Point

Quasi-convexity at a point controls segments from x₀ toward points with no greater function value.

f(x)≤f(x₀) ⇒ f(λx₀+(1−λ)x)≤f(x₀).

Source: Khademi (2026), Definition 7.7, p. 4245 ↗

Property

7.8 · First-Order Condition for Pointwise Quasi-Convexity

Pointwise quasi-convexity yields a directional gradient implication.

Source: Khademi (2026), Property 7.8, p. 4245 ↗

Property

7.9 · Quasi-Convexity Implies Pseudo-Convexity under Nonzero Gradient

On an open domain, pointwise quasi-convexity with a nonzero gradient implies pointwise pseudo-convexity.

Source: Khademi (2026), Property 7.9, p. 4245 ↗

Definition

7.10 · Midpoint Convex Function

Midpoint convexity requires the convex chord inequality only at the midpoint.

f((x+y)/2) ≤ [f(x)+f(y)]/2.

Source: Khademi (2026), Definition 7.10, p. 4246 ↗

Property

7.11 · Convexity Implies Midpoint Convexity

Every convex function is midpoint convex.

Source: Khademi (2026), Property 7.11, p. 4246 ↗

Property

7.12 · Continutiy Implies Midpoint Convexity

A continuous midpoint-convex function is convex.

Source: Khademi (2026), Property 7.12, p. 4246 ↗
