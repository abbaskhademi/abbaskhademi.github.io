# Abbas Khademi — Academic homepage (v16)

A static website for GitHub Pages, based on the v15 content with a flatter navigation and a minimalist academic presentation inspired by the layout approach of https://tonysf.github.io/. Uses its own turquoise color scheme and original content.

## What changed in v16

- No dropdown or nested menus. All eight navigation links lead directly to pages.
- CV removed from the **top navigation**; `cv.html` remains in the repository and can be opened from the **Links** page.
- Publication entries show the article title, authors, then a dedicated citation line containing the journal, volume(issue), page range and year. Both **Research > Published research** and **Publications > Published research** were updated.
- Simpler, lighter spacing, typography and dividers inspired by classic academic homepages; original turquoise palette and portrait preserved.
- Convexity Zoo blog chapters, source references, news and contacts preserved.

## Publish or update your site

1. Extract `Abbas-Khademi-Website-v16.zip` locally.
2. Open the `abbaskhademi.github.io` GitHub repository.
3. Upload all extracted files (including `assets/` and `.nojekyll`) to the repository root. For updating existing files, the simplest reliable method is to clone the repo and replace the files then commit, or upload the changed files in GitHub's web interface.
4. Confirm **Settings > Pages > Deploy from a branch > main > /(root)**.
5. After GitHub finishes deployment, check Home, Research, Publications and Blog on desktop and mobile.

`index.html` must be located at the repository root, not nested inside a folder. Do not upload only the ZIP.
