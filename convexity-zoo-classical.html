Definitions & main properties

Each numbered entry is based on the matching statement in the paper. Notes summarize the definition or the role of the result; see the original paper for all hypotheses and proofs.

Definition

2.1 · Convex Set

A set is convex when the segment between any two of its points stays inside it.

λx + (1−λ)y ∈ X, for x,y ∈ X and λ ∈ [0,1].

Source: Khademi (2026), Definition 2.1, p. 4218 ↗

Definition

2.2 · Convex Function

A convex function lies below the chord connecting any two values. Strict convexity requires a strict inequality for distinct points and interior weights.

f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y).

Source: Khademi (2026), Definition 2.2, p. 4218 ↗

Property

2.4 · Jensen’s Inequality

Finite convex combinations satisfy Jensen’s inequality.

Source: Khademi (2026), Property 2.4, p. 4218 ↗

Property

2.5 · Epigraph Criterion

A function is convex exactly when its epigraph is convex.

Source: Khademi (2026), Property 2.5, p. 4219 ↗

Property

2.6 · Sublevel Set Convexity

Every sublevel set of a convex function is convex; the converse generally fails.

Source: Khademi (2026), Property 2.6, p. 4219 ↗

Property

2.8 · Gradient Inequality

For differentiable functions, convexity is equivalent to a global first-order lower bound.

Source: Khademi (2026), Property 2.8, p. 4219 ↗

Property

2.9 · Second-Order Characterization

For twice differentiable functions, convexity is equivalent to a positive-semidefinite Hessian.

Source: Khademi (2026), Property 2.9, p. 4219 ↗

Definition

2.10 · Subgradient

A subgradient is a vector defining a global affine lower support to a convex function.

f(y) ≥ f(x) + ⟨ζ, y−x⟩ for every y ∈ X.

Source: Khademi (2026), Definition 2.10, p. 4219 ↗

Definition

2.11 · Strongly Convex Function

Strong convexity quantitatively strengthens the chord inequality by a positive quadratic margin.

f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y) − (μ/2)λ(1−λ)‖x−y‖².

Source: Khademi (2026), Definition 2.11, p. 4220 ↗

Property

2.12 · Strong First-Order Condition

Strong convexity is equivalent to a first-order lower bound with a quadratic margin.

Source: Khademi (2026), Property 2.12, p. 4220 ↗

Property

2.13 · Hessian Lower Bound

Twice differentiable strong convexity is equivalent to a uniform Hessian lower bound μI.

Source: Khademi (2026), Property 2.13, p. 4220 ↗

Property

2.14 · Quadratic Perturbation Characterization

Subtracting (μ/2)‖x‖² from f yields a convex function exactly in the strongly convex case.

Source: Khademi (2026), Property 2.14, p. 4220 ↗

Definition

2.15 · Uniformly Convex Function

Uniform convexity replaces the quadratic curvature term with a general positive modulus φ.

f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y) − λ(1−λ)φ(‖x−y‖).

Source: Khademi (2026), Definition 2.15, p. 4220 ↗

Property

2.16 · Local Equals Global

Any local minimizer of a convex objective on a convex domain is global.

Source: Khademi (2026), Property 2.16, p. 4221 ↗

Property

2.17 · First-Order Optimality

A first-order variational inequality characterizes global optima of differentiable convex objectives.

Source: Khademi (2026), Property 2.17, p. 4221 ↗
