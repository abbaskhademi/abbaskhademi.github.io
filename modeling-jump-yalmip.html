Modeling Optimization Problems in JuMP and YALMIP

A practical comparison of Julia/JuMP and MATLAB/YALMIP: continuous, integer, and binary decision variables, followed by the same mixed-integer quadratic programming (MIQP) model in both languages.

On this pageVariable typesMathematical modelJulia / JuMPMATLAB / YALMIPCheck the answerReferences

1. Types of decision variables

The modeling language controls the mathematical model; a compatible solver carries out the optimization.

Variable typeDomainJuMP (Julia)YALMIP (MATLAB)
Continuous\(x \in \mathbb{R}\)@variable(model, x)x = sdpvar(1,1);
Nonnegative continuous\(x \ge 0\)@variable(model, x >= 0)x = sdpvar(1,1);
Constraints = [x >= 0];
Integer\(y \in \mathbb{Z}\)@variable(model, y, Int)y = intvar(1,1);
Binary\(z \in \{0,1\}\)@variable(model, z, Bin)z = binvar(1,1);

You can define vectors and matrices of all three types using indexed JuMP declarations, or by supplying dimensions to sdpvar, intvar, and binvar in YALMIP.

2. A quadratic objective with linear constraints

Consider the following convex mixed-integer quadratic program (MIQP). The continuous variable x, integer variable y, and binary variable z interact through linear constraints. The objective is quadratic in x and y.

\[\begin{aligned} \min_{x,y,z}\quad & (x-2)^2+(y-3)^2+2z\\ \text{subject to}\quad & x+y+z \ge 4,\\ & 2x+y \le 7,\\ & x \le 5z,\\ & 0 \le x \le 5,\quad x\in\mathbb{R},\\ & 0 \le y \le 4,\quad y\in\mathbb{Z},\\ & z\in\{0,1\}. \end{aligned}\]

The linking constraint x ≤ 5z forces x = 0 whenever the binary variable is zero. Although the continuous quadratic objective is convex, the feasible set is nonconvex because of the integrality restrictions.

3. Implementation in Julia / JuMP

Install JuMP and Gurobi.jl. The Gurobi optimizer itself must also be properly installed and licensed.

Julia / JuMPDownload source ↓
# Install once in Julia:
# import Pkg; Pkg.add(["JuMP", "Gurobi", "MathOptInterface"])

using JuMP
using Gurobi
import MathOptInterface as MOI

# Create the model and choose an MIQP-capable solver.
model = Model(Gurobi.Optimizer)
set_silent(model)

# Decision variables
@variable(model, 0 <= x <= 5)       # Continuous
@variable(model, 0 <= y <= 4, Int)  # Integer
@variable(model, z, Bin)           # Binary

# Quadratic objective
@objective(model, Min, (x - 2)^2 + (y - 3)^2 + 2*z)

# Linear constraints
@constraint(model, x + y + z >= 4)
@constraint(model, 2*x + y <= 7)
@constraint(model, x <= 5*z)

optimize!(model)

if termination_status(model) == MOI.OPTIMAL
    println("x = ", value(x))
    println("y = ", value(y))
    println("z = ", value(z))
    println("Optimal objective = ", objective_value(model))
else
    println("Termination status: ", termination_status(model))
end

JuMP uses @variable, @constraint, and @objective to construct the model, then optimize! to solve it.

4. The same implementation in MATLAB / YALMIP

Install YALMIP and ensure a compatible MIQP solver such as Gurobi is available in MATLAB.

MATLAB / YALMIPDownload source ↓
% Requires MATLAB + YALMIP + an installed, licensed MIQP solver.
% Example solver: Gurobi.
yalmip('clear');

% Decision variables
x = sdpvar(1,1);  % Continuous
y = intvar(1,1);  % Integer
z = binvar(1,1);  % Binary

% Linear constraints, including variable bounds
Constraints = [x >= 0, x <= 5, ...
               y >= 0, y <= 4, ...
               x + y + z >= 4, ...
               2*x + y <= 7, ...
               x <= 5*z];

% Quadratic objective
Objective = (x - 2)^2 + (y - 3)^2 + 2*z;

options = sdpsettings('solver', 'gurobi', 'verbose', 0);
diagnostics = optimize(Constraints, Objective, options);

if diagnostics.problem == 0
    fprintf('x = %.6f\n', value(x));
    fprintf('y = %.6f\n', value(y));
    fprintf('z = %.6f\n', value(z));
    fprintf('Optimal objective = %.6f\n', value(Objective));
else
    fprintf('Solver issue: %s\n', diagnostics.info);
end

YALMIP represents the problem with Constraints and Objective, calls optimize, and reads the numerical solution using value.

5. Expected optimal solution

x*2
y*3
z*1
Objective2

At \((x,y,z)=(2,3,1)\), all linear constraints hold and the objective is 2. For \(z=1\), both squared terms are nonnegative, so the objective cannot be below 2. For \(z=0\), the linking constraint gives \(x=0\), and the remaining constraints force \(y=4\), yielding objective 5. Therefore, the displayed solution is globally optimal.

This solution is verified analytically; the downloadable code has not been executed in a Julia or MATLAB runtime here. Small numerical differences (for example, 0.999999 instead of 1) can occur because of solver tolerances.

QP, MILP, and MIQP: what changes?

  • QP: Relax integer and binary restrictions, so all decision variables are continuous, with \(0\le z\le1\).
  • MILP: Keep integer and binary restrictions, but use a linear objective.
  • MIQP: Keep integer and binary restrictions with a quadratic objective and linear constraints—as in this example.

Solver note: MATLAB's quadprog is for continuous quadratic programming and does not directly enforce integer/binary variables. Likewise, a solver supporting LP, MIP, and QP separately is not necessarily an MIQP solver. Gurobi is used in both scripts for consistency.
